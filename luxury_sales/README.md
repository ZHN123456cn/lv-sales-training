# 奢侈品销售知识库（教练 Agent 专用）

## 用途

本知识库**只服务于教练 Agent**。在销售与模拟客户 Agent 完成对话实战后，教练 Agent 调用本库，对销售的表现进行**打分与点评**。

本库提供的是**打分点评所需的知识依据**，不包含评分维度、分值与客户画像/陪练场景（这两部分已在 Agent 实现中具备）。

## 教练 Agent 如何使用本库

针对销售在对话中的每一句关键表现，教练可从本库检索对应条目，核对四件事：

1. **事实对不对** —— 销售讲的品牌历史、产品故事、服务政策、工艺细节是否准确（见各条「核心事实」）。
2. **该说的点说没说** —— 在该场景下，专业销售应覆盖哪些关键点（见各条「销售应说到的关键点」）。
3. **话术好不好** —— 销售的表达与「推荐话术（正面范例）」的差距。
4. **有没有踩坑** —— 是否触犯「常见错误（反面）」中的高压、贬低、错误价值解释等行为。

## 条目结构（统一格式，便于切分入库）

每个知识条目包含以下字段：

```
## 条目标题
**核心事实**：可被核对的客观信息
**适用场景**：客户说了什么 / 处于哪个销售环节时调用本条
**销售应说到的关键点**：教练用来核对"是否说全"的清单
**推荐话术（正面范例）**：可作为标准答案参照
**常见错误（反面）**：需要扣分/指出的错误行为
```

## 目录

| 文件 | 内容 | 教练用途 |
|---|---|---|
| `01_LV品牌基础.md` | 品牌历史、Art of Travel、Monogram、Asnières、Savoir-faire | 核对品牌故事讲得对不对、价值塑造到不到位 |
| `02_LV产品基础.md` | Speedy / Keepall / Alma / Neverfull / Noé / Capucines 等款式 | 核对产品介绍是否准确、是否匹配客户需求 |
| `03_门店服务礼仪.md` | 迎宾、距离感、观察、递拿、试用、包装、告别、售后 | 核对服务流程与礼仪是否到位 |
| `04_需求挖掘.md` | 自用/送礼/商务/旅行场景、开放式提问、复述、风格与预算判断 | 核对销售有没有先挖需求再推产品 |
| `05_价值塑造与异议处理.md` | 太贵、网上/代购便宜、比竞品、再想想、怕过时、怕送错、售后 | 核对异议处理是否专业、是否高压逼单 |
| `06_送礼推荐策略.md` | 各类收礼人、各类节庆场景、个性化定制、礼品包装 | 核对送礼推荐是否合理、信息是否准确 |
| `07_优秀话术与不佳话术对照.md` | 各环节正面话术 vs 反面话术对照 | 作为话术好坏的快速参照表 |

## 资料来源说明

事实部分主要依据 Louis Vuitton 官方页面（品牌服务、维修、礼品包装、个性化、Monogram、Trunks、Speedy、Keepall、Alma、Speedy P9）与 LVMH / LV 招聘的 Client Advisor 岗位说明；销售方法部分参考《Selling Luxury》、CNFCE 奢侈品销售仪式课程、Elevify 奢侈品销售课程，以及关于"高压销售损害复购意愿"的零售研究。详见根目录 `zhishiku.md`。
