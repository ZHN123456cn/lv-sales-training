System Overview

系统架构

基于大语言模型的智能销售培训系统，融合多模态 RAG 检索与教练点评能力。

Agent 核心

基于 ReAct 模式的智能代理，支持多轮对话、工具调用与记忆管理，实现自然语言交互。

RAG 检索系统

四层检索架构：关键词搜索、目录索引、FTS5 全文检索、向量语义搜索，智能融合结果。

教练 Agent

专业教练角色，对销售表现进行四维度打分与点评：事实准确性、关键点覆盖、话术质量、行为规范。

MCP 协议

标准化工具调用协议，支持工具发现、动态调用与结果返回，便于扩展与集成。
